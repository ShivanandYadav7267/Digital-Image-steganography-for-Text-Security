# Digital Image Steganography for Text Security

## 📌 Description

Digital Image Steganography for Text Security is a Python-based application that allows users to securely hide text messages inside digital images and extract them when required.

The project uses **image steganography techniques** to embed secret text into an image without significantly changing its visual appearance. It provides a simple graphical user interface built with **Tkinter** and uses **Pillow** for image processing.

## 🚀 Features

* 🔐 Hide secret text inside an image
* 🔓 Extract hidden text from an image
* 🖼️ Supports image processing using Pillow
* 🖥️ Simple and user-friendly GUI
* 🐍 Developed using Python
* 🔒 Useful for learning information security and steganography

## 🛠️ Technologies Used

* **Python**
* **Tkinter**
* **Pillow (PIL)**

#📂 Project Purpose

The main purpose of this project is to demonstrate how digital images can be used to securely conceal text information and to provide a practical understanding of **digital steganography** and basic information-security concepts.

## ▶️ How to Run

1. Clone this repository.
2. Install the required dependency:

```bash
pip install pillow
```

3. Run the Python application:

```bash
python main.py
```
